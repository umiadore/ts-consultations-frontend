# TodoApp

## #Создание_структуры
- [ ] Создать функциональный компонент `TodoApp.tsx` с `useState`
- [ ] Определить два состояния:
  - `tasks` — массив задач
  - `newTask` — текст новой задачи

## #Определение_интерфейса
- [ ] Определить интерфейс `Task` с полями:
  - `id` (number) — уникальный идентификатор задачи
  - `text` (string) — текст задачи
  - `completed` (boolean) — статус выполнения

## #Добавление_задачи
- [ ] Написать функцию `addTask`:
  - [ ] Проверить, что строка с задачей не пустая
  - [ ] Добавить задачу в `tasks` с уникальным `id`
  - [ ] Очистить поле ввода

## #Переключение_статуса
- [ ] Написать функцию `toggleTask`:
  - [ ] Изменяет статус выполнения задачи при клике

## #Удаление_задачи
- [ ] Написать функцию `deleteTask`:
  - [ ] Удаляет задачу по её `id`

## #Рендеринг
- [ ] Отобразить задачи в `<ul>` `<li>`:
  - [ ] Текст задачи (выделение при выполнении)
  - [ ] Кнопка удаления

## #Стилизация
- [ ] Создать `TodoApp.module.css`
- [ ] Добавить стили:
  - [ ] Контейнер
  - [ ] Входное поле
